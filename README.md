# Channel Watch

Сайт со списком каналов, их активностью за 30 дней и уведомлением в Telegram, если канал молчит.

- Сайт: `docs/index.html` (обычная статическая страница).
- Проверка: `check.py` раз в 3 часа через GitHub Actions, бесплатно.
- Порог тишины: 2 дня (меняется в `channels.json`, можно задать свой для каждого канала).

## Что работает сейчас

| Платформа | Статус |
|---|---|
| YouTube | работает, данные берутся из открытых RSS-лент, ключ не нужен |
| TikTok | в списке отображается, данные пока не собираются |
| Instagram | в списке отображается, данные пока не собираются |

У TikTok и Instagram нет бесплатного официального API для чужих каналов. Подключается отдельным шагом
(например, через Apify): достаточно заменить функции `fetch_tiktok` и `fetch_instagram` в `check.py`,
они должны вернуть `{"title", "channel_url", "videos": [{"id","title","published","url"}]}`.

## Запуск за 10 минут

1. **Свои каналы.** Откройте `channels.json`, замените примеры на свои: `"handle": "@имя"` или `"channel_id": "UC..."`.
2. **Telegram-бот.** В Telegram напишите @BotFather, команда `/newbot`, сохраните токен.
   Напишите своему боту любое сообщение, затем откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":...}`, это ваш `TG_CHAT_ID`.
3. **GitHub.** Создайте репозиторий, загрузите в него все файлы этой папки.
   Settings → Secrets and variables → Actions → добавьте секреты `TG_BOT_TOKEN` и `TG_CHAT_ID`.
4. **Сайт.** Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/docs`.
5. **Первый запуск.** Вкладка Actions → check-channels → Run workflow. Дальше всё идёт само.

Бесплатный GitHub Pages публичный: данные о каналах будет видно всем, у кого есть ссылка.
Если нужен закрытый сайт, лучше разместить его на своём сервере или за паролем.

## Добавление каналов с сайта (удобно с телефона)

На сайте есть кнопка **«＋ Добавить каналы»**. Вставляете ссылки (по одной на строку, можно сразу много),
нажимаете «Добавить». Сайт сам допишет их в `channels.json` и запустит проверку, через 2–3 минуты каналы появятся.

Распознаются ссылки вида:

- `youtube.com/@имя`, `youtube.com/channel/UC...`, `youtube.com/c/имя`, `youtube.com/user/имя`
- `tiktok.com/@имя`
- `instagram.com/имя`

Ссылки на отдельные видео и публикации не подойдут, нужна ссылка именно на канал или профиль.
Название канала для YouTube подтянется само. Удалить канал можно крестиком в углу его карточки.

**Один раз нужно создать токен GitHub** (это «ключ», который разрешает сайту редактировать список):

1. Откройте https://github.com/settings/personal-access-tokens/new
2. Name: `channel-watch`, Expiration: например, 1 год.
3. Repository access: **Only select repositories**, выберите ваш репозиторий.
4. Permissions → Repository permissions: **Contents: Read and write** и **Actions: Read and write**.
5. Generate token, скопируйте его.
6. На сайте нажмите «＋ Добавить каналы», вставьте токен и название репозитория (`логин/channel-watch`).

Токен хранится только в браузере того устройства, где вы его ввели, и не попадает на сайт или в репозиторий.
На каждом новом устройстве (телефон, компьютер) его нужно ввести один раз. Через год, когда токен истечёт,
создайте новый тем же способом (кнопка «Настройки» в форме).

## Как работают уведомления

- За один запуск приходит одно сводное сообщение со списком молчащих каналов.
- О канале сообщается, когда он вышел за порог (🟡), и ещё раз, если тишина дошла до 7 дней (🔴, `dormant_days`).
- Как только появляется новое видео, счётчик сбрасывается.
- Если загрузка канала не удалась, уведомление не отправляется (чтобы не было ложных тревог).

## Локально

```
python check.py          # реальная проверка, пишет docs/data.js
python check.py --demo   # демо-данные для предпросмотра
```

Откройте `docs/index.html` двойным кликом. Python 3.8+, сторонних библиотек не нужно.
